# Find Your Levels

A practical field guide to reading price action, participation, volume, and meaningful levels.

GitHub Pages publishes root `index.html` from `main` at [findyourlevels.com](https://findyourlevels.com/). The `CNAME` file preserves the custom domain.

The seven-chapter content source is `CONTENT_REVISION_BLUEPRINT.md`. The implementation and build instructions are in [v3/README.md](v3/README.md). The generated root page uses assets from `v3/`; `/v3/` remains a local/review entry point with `noindex`.

To preview locally, serve the repository root and open `/` or `/v3/`.
